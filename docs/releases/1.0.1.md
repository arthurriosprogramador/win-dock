WinDock 1.0.1

- Atualizações automáticas com confirmação antes de baixar e instalar.
- Janela de prévia maior, redimensionável e com seletor de temas integrado.
- Ajustes de contraste, cores dos controles e efeito de hover.
- Correção do foco do campo de pesquisa ao clicar para digitar.
- Ajustes no MSI para solicitar o encerramento do WinDock durante a manutenção e desativar o fechamento de outros aplicativos pelo Restart Manager.

Baixe **WinDock.msi** para instalar manualmente. A build local 1.0.0 com o atualizador pode detectar esta versão em **Verificar atualizações**. A versão 1.0.0 originalmente publicada não possui o atualizador e precisa da instalação manual.

Se o Windows encontrar arquivos realmente bloqueados, poderá solicitar uma reinicialização posterior. A instalação não reinicia o computador automaticamente.
